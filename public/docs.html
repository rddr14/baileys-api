Referência da API RESTful (Baileys + EvoAPI v2)

API multi-sessão baseada em Baileys com compatibilidade direta com Evolution API v2 e rotas nativas. Todas as rotas Evolution respondem tanto na raiz (ex: /message/sendText/{instance}) quanto sob /api.

1. Dual-Layer Routing

Use rotas no padrão Evolution API na raiz ou com prefixo /api. O sistema Laravel (EvolutionApiService e BaileysApiService) funciona de forma transparente.

2. 9º Dígito (BR) & Desduplicação @lid

Números brasileiros com ou sem o 9º dígito são resolvidos via onWhatsApp e casados pelos últimos 8 dígitos. Registros @lid são mesclados ao JID real sem duplicar contatos.

3. name vs pushName

name representa o nome salvo na agenda da sessão; pushName (com alias pushname) traz o nome público do perfil no WhatsApp, com fallback inteligente entre sessões.

4. Proteção Anti-Bloqueio Pix & 2FA

Suporte aos 4 modos: smart_fallback (aguarda 2 checks), dual (botão + código puro), text_only (Kill-Switch) e button_only.

5. Webhooks & Retries

Dispara messages.upsert, messages.update, message-receipt.update, connection.update, labels.edit e labels.association com até 3 tentativas automáticas.

POST /instance/create

Criar ou inicializar instância

Cria uma nova instância e inicia o socket Baileys. Aceita webhook como string ou objeto { url, enabled } e aplica alwaysOnline/showOnline se informado.

curl -X POST "https://baileys.novo.quarkgps.com/instance/create" \
  -H "Content-Type: application/json" \
  -d '{
  "instanceName": "minha_instancia",
  "alwaysOnline": false,
  "webhook": {
    "enabled": true,
    "url": "https://meusite.com/webhook"
  }
}'
$response = Http::withHeaders([
    "Content-Type" => "application/json",
])->post("https://baileys.novo.quarkgps.com/instance/create", [
    "instanceName" => "minha_instancia",
    "alwaysOnline" => false,
    "webhook" => {"enabled":true,"url":"https://meusite.com/webhook"},
]);

$data = $response->json();
const response = await fetch("https://baileys.novo.quarkgps.com/instance/create", {
  method: "POST",
  headers: {
      "Content-Type": "application/json"
  },
  body: JSON.stringify({
      "instanceName": "minha_instancia",
      "alwaysOnline": false,
      "webhook": {
          "enabled": true,
          "url": "https://meusite.com/webhook"
      }
  })
});
const result = await response.json();
